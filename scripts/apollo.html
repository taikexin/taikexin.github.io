IP UNIVERSE DESIGN

Apollo · 世界观设计方案

清北网校 IP「小北」宇宙 · 顶层设计全案 · 完整呈现

知识就是力量，知识改变世界。
成为教育类爆款产品，打造超级知识产权（IP, Intellectual Property）。
01

顶层设计

TOP LEVEL

遥远的 X 宇宙，有一颗智慧星球（瓜瓜龙和 Gogokid 所在的星球），与它遥相呼应的是我们的清北星球。故事发生在清北星球的清北小镇上，IP 主角小北就生活在这里。

在这里生活的孩子们，有温暖的家和知心的朋友，他们健康快乐、自由自在地长大。通过不断的成长，他们都将逐渐成为善良、诚实、谦虚、守信、勇敢的人，并逐渐树立起这样的理想：做一个有知识、受人尊重、为世界做贡献的人。

有一天，从天而降的大萌打破了小北平静的生活。两人在相处中成为好朋友，并和其他小伙伴组成清北战队。为了维护世界和平，清北战队通过探索世界、不断增长知识、收集能量，对抗来自另外一个星球的邪恶势力。

时间
2046 年
空间
充满知识能量的 X 宇宙：神奇的星球科技发达，遍布高科技与人工智能；未来 20 多年，人工智能解放了大量劳动力
特征
知识就是一切力量的源泉——只有掌握知识，才能搜集能量、维护和平
规则
距银河系 35 光年的阿尔法星系，有一颗存在了 48 亿年的清北星球；存在了 55 亿年的紫荆星，坐落在距它 51 亿公里的宇宙深处
02

故事脉络

STORYLINE

矛盾点

正反派一起争夺知识能量：大王子大萌不愿与弟弟争夺王位，离开紫荆星球来到清北小镇；二王子二萌为抢夺大萌继承的知识力量追到小镇，打破了宁静。

清北战队

大萌与小北等人成为好友。二萌入侵使小镇陷入混乱，小北和伙伴们组建清北战队——不断学习新知识、掌握能量，对抗外部邪恶势力。

交通与通信

小镇主要交通工具是人工智能驾驶的公交车；穿梭星球靠宇宙飞船。通信从超智能手机，到大萌赠送的「超级眼镜」专属信道。

主题曲

作用：洗脑、强化品牌记忆。位置：课前或课间播放，满足品宣需求。形式：MV + 5 秒内的过场 slogan 音乐。

03

空间关系

UNIVERSE MAP

一片浩瀚的 X 宇宙，漫天繁星蕴含各种知识能量；坐上飞船遨游，可以看到各种由知识组成的美丽星球。清北星球充满知识，人工智能、飞船、高科技遍布各个角落——除各学科大陆外，皆是知识海洋。清北小镇坐落在数学大陆上；数学大陆、英语大陆、语文大陆在清北星球，知识星球在 X 宇宙。

X 宇宙

漫天繁星蕴含知识能量，由知识组成的美丽星球散落其间。

阿尔法星系

距银河系 35 光年，清北星球与紫荆星所在星系。

清北星球

学科大陆 + 知识海洋：数学大陆、英语大陆、语文大陆。

04

人物关系与角色设计

CHARACTERS

皮克斯动画工作室创始人之一拉塞特曾说：「皮克斯的故事必须与主角的成长以及如何改变有关。」每个角色经历冒险后认识自己、迅速成长，观众也在观影过程中陪伴角色完成一次成长——成长与改变是本世界观人物关系的内核。

小北 × 大萌

反差萌 CP：一个急吼吼，一个慢吞吞，能力和性格互补。

大萌 × 鹦鹉

欢喜冤家 CP：一个慢条斯理，一个絮絮叨叨，互相争宠。

小北 × 小清

同学组 CP：一个调皮胆小又机智，一个傲娇胆大又心细，两小无猜。

05

成长脉络

GROWTH PATH

世界观跟随学龄段层层扩展——小镇 → 生活 → 世界 → 宇宙，守护的范围随孩子的认知一同长大。

幼小衔接探索社区
维护清北小镇和平
小学低段 1-2探索生活
维护清北小镇和平
小学中段 3-4探索世界
维护清北星球和平
小学高段 5-6探索未知
维护阿尔法星系与 X 宇宙和平

清北小镇（幼小衔接）

小北和妹妹在清北小镇出生。妹妹通过瓜瓜龙网课学习数学思维，二人都很喜欢瓜瓜龙。一天小北放学路上遇到麻烦，被路过的大萌用神奇道具解救，从此成为好朋友。

清北小镇（1-2 年级）

大萌对小镇一切充满好奇，像多啦A梦一样拥有很强的数学思维能力和神奇科技道具。相处中感情日益深厚，组成清北战队，集结智慧、收集能量。

清北星球（3-4 年级）

清北星球遭入侵，大萌被迫揭露大王子身份。二萌担忧王权不稳，不断制造麻烦。大萌带小北探索未知领域、获得知识能量，与二萌斗智斗勇。

X 宇宙（5-6 年级）

清北星球的知识能量有限。为对抗二萌日益猛烈的攻势，清北战队把目光投向更远的其他星系、乃至整个 X 宇宙，开启更强大的知识能量收集。

06

数学场景

MATH SCENES

清北小镇

与现实生活方式无异的小镇：博物馆、商业区（奶茶店、糖果店、水果店）、居住区、游乐园、学校、体育馆、警察局、消防局、医院、动物园一应俱全。各种有趣的知识藏在小镇的各个角落，小北和伙伴们通过探索知识、集结能量来解决问题、实现愿望。

几何城

由各种神奇几何图形建筑组成的城市，蕴藏神秘能量「几何之源」。它被城市密码保护，只有破解所有几何建筑内的数学难题，才能夺得几何之源。小伙伴们运用几何知识破解密码、阻止二萌，并用几何之源恢复被破坏的城市。

运算岛

数学大陆的知识能量汇聚地，岛中心的「运算之心」维持整个大陆的能量稳定。二萌突袭藏匿之所，守卫们趁乱将运算之心分为 N 块封印在岛屿各处。清北战队必须根据残留线索，抢在二萌之前找齐碎片并重组，恢复岛屿运转。

07

美术风格与形象手册

ART STYLE

阿波罗项目的美术风格参考与「小北」品牌形象基础手册，为动画量产确立统一视觉标准；动画的故事情节、主 IP 与真人老师及游戏化设计紧密连接，避免动画情节与知识讲解之间的割裂感。

08

设计思路

DESIGN THINKING

课程形式

类别：网校大班课；展现类型：系列剧（每个阶段一个故事）；动画时长：1-3 分钟；课程路径：30+10+30。

动力系统

将游戏化八大要素嵌入世界观：史诗意义与使命感、进步与成就感、创意授权与反馈、所有权与拥有感、社交影响与关联性、稀缺性与渴望、未知性与好奇心、亏损与逃避心——让孩子有陪伴感、参与感，进入心流、主动学习。

设计出发点（九条原则）

  • 人生观、价值观、世界观「三观合一」
  • 体现陪伴，利于 6-12 岁孩子的成长（伴学设计的重要性分析）
  • 与学科相关联（数学、语文、英语），利于展开教学
  • 与品牌强关联（清北网校），与 IP 小北、鹦鹉相关联
  • 游戏化：使命感、成就、创造、拥有、社交、稀缺、未知、逃避
  • 正面积极：没有绝对的善与恶；有反派角色、有达成目的；有科技感与各种道具，趣味性强
  • 设计落地性好，尽可能降低生产成本
  • 围绕课程的引入、易错强调、重点强调等环节创作，世界观故事贯穿整节课
  • 构建一个虚拟 IP：全能的稀有动物（或非生物角色），倾向于超能陆战队里的「大白」

优势点与爆款策略

优势点

① IP 经济带动，打造清北 IP 爆款，口碑与商业双价值；② 嵌入动力系统（自我决定论：自主、胜任、归属）与游戏化；③ 基于 6-12 岁儿童发展心理学理论设计；④ 基于对经典和爆款 IP 的深入研究；⑤ 行业丰富经验的动画团队。

爆款策略

宏观策略：打造头部爆款、传递文化内涵、形成流量矩阵。集中资源（产品、内容、教学、服务、运营）协作冲刺头部；通过品牌 IP 化对用户形成持久记忆与关注，增强粘性与影响力；内容拓展空间广阔，可持续强化单一 IP 或借力延伸。
